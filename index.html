Vos questions

Questions fréquentes

Comment choisir un véhicule ?

Vous pouvez consulter le catalogue ou nous transmettre la marque, le modèle, l’année, la boîte de vitesses et votre budget. Nous vous orienterons vers les options possibles.

Quels sont les délais d’importation ?

Les délais varient selon la disponibilité du véhicule, sa préparation, le transport maritime et les formalités applicables. Ils sont confirmés dans votre proposition personnalisée.

Le véhicule est-il inspecté avant expédition ?

Une inspection peut être proposée selon la formule retenue. Les modalités précises sont expliquées dans le devis.

Que comprend le devis ?

Le devis précise les éléments inclus dans votre projet. Demandez une explication détaillée avant toute validation.

Puis-je commander un modèle absent du catalogue ?

Oui. Envoyez-nous les caractéristiques du véhicule souhaité ; nous étudierons les possibilités avec nos partenaires.

Comment vous contacter rapidement ?

Utilisez le formulaire de devis ou le bouton WhatsApp présent en bas à droite de la page.
